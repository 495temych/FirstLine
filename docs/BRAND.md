# Brand

The dashboard is a route. A run moves down a line through its stations, and a human gate is a signal that holds it.

## Fonts

From Google Fonts:

- **Headings and body**: Familjen Grotesk
- **Tools, queues and other identifiers**: IBM Plex Mono

## Colors

- **Paper**: `#E9EEF0`
- **Panels**: `#FFFFFF`
- **Ink**: `#12263A`
- **Signal amber**: `#F2B705`. Use it for human gates and nothing else.

The dashboard has one light theme, whatever the system setting.

Each path has one color, which the route line takes on.

- **Self-serve**: `#1B7A4B`
- **Auto-fix**: `#2450B2`
- **Escalate**: `#B4470F`
- **Out of scope**: `#5B6875`
- **No tools**: `#6A3FB5`

## Layout

The ticket sits on the left and its route on the right, stacking at phone width. Keep the route line as the one bold element, and keep everything else quiet and tabular.

## Avoid

- Decorative motion. This is a tool people use all day.
- All-caps labels, and borders on one edge of a panel.

## Tone

Plain English, sentence case and no exclamation marks. Name a button after what it does, such as "Run fix". Money in francs is written as CHF 2'000.
