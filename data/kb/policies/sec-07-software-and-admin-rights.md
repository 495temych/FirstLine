# SEC-07: Software and admin rights

**Category:** Policy | **Owner team:** Security | **Last reviewed:** 2026-11-07

**§7.1 Admin rights.** Standard users run without local admin rights.

**§7.2 Installing software.** Software comes through the Company Portal or Software Center catalog, or a `SR-SOFTWARE` request with manager approval.

**§7.3 Blocked installers.** An installer blocked by endpoint protection is never worked around. The exception goes to `SEC-POLICY`.
